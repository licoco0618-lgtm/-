## 🌟 核心功能一覽

1. **📋 每日聯絡簿 & 教室日誌**：
   - 填寫每日 7 節課教學進度、任課老師、隨堂作業、測驗與班務交代。
   - **⚡ 一鍵帶入今日課表**：自動根據當天星期幾將課表科目與任課老師填入表格。
   - **📢 一鍵生成 LINE 班群公告**：自動格式化產出包含「明日課表預覽」、「今日作業與催繳」、「近期測驗提醒」、「導師翁偉倬老師叮嚀」及「黑板每日一句」。
   - **🖨️ 教室日誌列印**：內建乾淨列印格式。

2. **📝 作業登記與座號催繳盤**：
   - **1~42 號視覺座號矩陣**：點擊座號一鍵循環切換 `已交 (綠)` ➔ `缺交 (紅)` ➔ `補交 (藍)` ➔ `請假 (灰)`。
   - **📋 一鍵複製催繳訊息**：自動抓取缺交座號發送到班群。

3. **⏰ 小考與段考倒數衝刺**：
   - 即時倒數第一次段考（會計學、數位科技、文書處理、多媒體製作、商概、國英數等）。

4. **📅 互動課表 & 小老師名冊**：
   - 包含週一至週五 7 節課、教室地點（如資處工場三、音樂教室）與各科小老師名冊。

5. **✨ 黑板每日一句 & 教室佈置靈感庫**：
   - 擬真木框黑板展示區，精選會計箴言與導師叮嚀。

6. **👥 座號名冊與備份管理**：
   - 學生跨科缺交作業檢視、批量貼上匯入與 JSON 備份還原。
